### 6.1 実験宣言セル: 共通の設定・検証すること・判定基準・前提条件

#### 共通の設定

- **第 1 段とコーパス**: 024 の学習済みモデル(凍結)で埋め込んだ L2 正規化済みのベクトル。使う 9,470 記事から切り出した passage 94,486 個(長さ 128 トークン)と query 94,066 個(長さ 32 トークン)で、query の正例は、同じ記事の、元の passage 以外の passage。評価の query は、評価用の記事 1 本あたり実験 A〜C で 3 個(約 900 個)、実験 D・E で 5 個(約 1,500 個)、実験 F で 2 個(約 600 個)、検証用の記事で 10 個(877 個)で、ブートストラップは記事を単位とする。
- **近似最近傍探索**: 目標の recall は 0.9、費用は距離計算の回数(3.9 節)。HNSW は $M = 5$、$efConstruction = 100$、転置ファイルはリスト数 $K = \mathrm{round}(\sqrt{N} \times \{1/2, 1, 2, 4, 8\})$ の 5 点、Product Quantization は $m = 32$、$k^* = 256$(符号 32 バイト、圧縮率 32 倍)。
- **並べ替えモデルと学習**: 008 と同じ小型 GPT から始め、全パラメータを更新する(cross-encoder は終端の位置の出力からスカラーのスコアを出し、dual encoder は 024 の C5 と同じ構成)。1 ステップは $B = 8$ 個の query × (正例 1 個 + 負例 $n = 7$ 個)で、損失は 8 個の候補の softmax 交差エントロピー。学習ステップ数 $T$ の候補は $(1024, 512, 256)$ で、全条件で同じ $T$ を使う。正例は、採掘した第 1 段の上位 50 件の中の同じ記事の passage から選ぶ(3.7 節)。評価は、第 1 段(コーパス全体の全探索)の上位 $K = 50$ 件を並べ替えた Recall@10(同点は正例に不利に数える。3.9 節)で、$R(c)$ を条件 $c$ の値とする。
- 実験 D・E の結論は、008 の`main`と 024 のチェックポイントから始めた場合に限る(詳細は付録 C.5)。

#### 揃えた量と、学習量についての注意

起点・更新するパラメータ・学習ステップ数・バッチ・損失の形・評価の候補と指標は全条件で揃え、学習で見た query と正例の系列は同じシードの条件どうしで揃える。負例は D1 と D2 で揃え、E2 だけ揃えない(実験 E の介入)。モデルの構造は揃えない(実験 D の介入)。学習率は揃えず、条件ごとに較正する。見た事例数を揃えたので、cross-encoder の方が計算量は大きく、実験 D は同じ計算量での比較ではない(付録 C.1)。

学習に使える query は 39,303 個(学習用の query 89,803 個の 43.77%。ローカルの MPS での値)で、$T = 1024$・$512$・$256$ は約 **0.208・0.104・0.052 エポック** にあたり($8T / 39{,}303$)、学習が飽和していない状態での比較になりうる。cross-encoder は立ち上がりが遅く、**実験 D の対比量を負の向きに偏らせうる**。「並べ替えを足すと上がる」ことは追加の学習量と交絡するので、判定の対象にしない(付録 C.2)。

#### 学習率の較正(本番の冒頭、6.5 節)

条件ごとに、中心 $2.4 \times 10^{-4}$(024 の C2 を起点にした仮置き)の $\{1/16, 1/4, 1, 4, 16\}$ 倍(公比 4 の 5 点)を、較正専用のシード(番号 90)で学習し、較正の query(検証用の記事)での、並べ替えた後の **平均逆順位(Mean Reciprocal Rank)** が最大の学習率を選ぶ。評価用の記事の query は使わない。P1(a)を満たさない学習率は候補から外し、最良が格子の端に来たときは 1 点だけ拡張する(規則の詳細は付録 C.6)。

#### 共通の前提条件

前提条件は、検証したい仮説とは独立な量で定義する。成立しなかった実験は、支持・反証・判定不能のいずれとも判定せず「前提不成立」として記録する。

- **P0(較正、実験 D・E)**: その実験の対比量に入る条件で、選んだ学習率が格子の内点であること(すべての格子点が候補から外れた場合も不成立)。
- **P1(学習の成立、実験 D・E)**: 学習前のモデル(更新なし)では成立しない量で、学習前との差がそのばらつきの 2 倍以上という統計的な基準で定義する。(a)その実験の対比量に入る全条件・全シードで、訓練損失がすべてのステップで有限であり、最後の 5% のステップの、訓練損失と **同じ組での学習前のモデルの損失** の差 $d_t$ の平均 $\bar{d}$ が $\bar{d} \le -2 \, \mathrm{SE}$($\mathrm{SE}$ は標準誤差)で、かつ、その区間の訓練損失の平均が一様な予測の損失 $\ln(1 + n)$ 未満であること。(b)基準の条件(実験 D: D2、実験 E: E2)の、較正の query での Recall@10 の、学習前のモデルからの増分のシード平均 $\bar{g}$ が $\bar{g} > 0$ かつ $\bar{g} \ge 2 \, \sigma_g$ であること($\sigma_g$ は判定と同じ式の標準偏差)。更新がない学習では(a)も(b)も不成立になる(6.14 節)。この閾値は統計的に有意な低下・上昇を要求するので、学習が進んでいても差がばらつきに埋もれれば不成立になる。パイロットでは、D1 の余裕が小さかった(最後の区間の訓練損失 2.0619 に対して閾値 $\ln(1 + n) = 2.0794$)。詳細は付録 C.7。
- **P2(改善の余地、実験 D・E)**: 基準の条件の Recall@10 が coverage より 0.05 以上低いこと(coverage は、第 1 段の上位 50 件に正例が入る query の割合)。
- **P3(第 1 段の候補、実験 D・E)**: coverage が 0.35 以上で、coverage から並べ替えなしの Recall@10 を引いた並べ替えの余地が 0.10 以上であること。
- **P0(B)(実験 B)**: 転置ファイルの 5 点のリスト数のうち、費用の対数が最小のものが内点であること。
- **P1(A)・P1(B)(実験 A・B)**: すべてのシード・水準・索引で、格子の最小点の recall が目標未満で、掃引の中で目標以上になること。再標本のうち補間できないものが 1% 以下であること。
- **P2(C)(実験 C)**: 対称距離計算の recall の平均が 0.10 以上 0.90 以下であること。

#### 判定の形と標準偏差の単位

対比量 $\Delta$ は、同じシードどうしで作った量 $d_s$ のシード平均で、標準偏差は

$$
\sigma = \sqrt{\frac{\mathrm{Var}_s(d_s)}{n} + \sigma_{\mathrm{boot}}^2}
$$

とする($n$ はシード数、$\mathrm{Var}_s$ はシード間の不偏分散、$\sigma_{\mathrm{boot}}$ は記事を単位とする対応付きのクラスタブートストラップ(反復 10,000 回)で対比量を作り直したときの標準偏差)。評価の query は全シードで共通で、その有限性による変動はシード間の分散に現れないので、第 2 項で補う(導出は付録 C.8)。判定は 3 値で、閾値は $2\sigma$ とする: **支持** は $\Delta > 2\sigma$、**反証** は $\Delta < -2\sigma$、**判定不能** は $\lvert \Delta \rvert \le 2\sigma$。

#### 実験 A: HNSW の探索の費用の件数への依存性

**検証すること**: HNSW が目標の recall 0.9 に達するための 1 query あたりの距離計算の回数 $c(N)$ の、索引の件数 $N$ に対するべき指数 $b$($c \propto N^{b}$)が 1 より小さいか(費用が $N$ に対して劣線形に増えるか)。$N$ は入れ子の部分集合による公比 2 の 5 点($N_{\max} / 16, \dots, N_{\max}$)で、次数 $M$ と構築時の探索の幅は全水準で固定する。正解は、その水準の部分集合での全探索の上位 10 件。

**判定基準**: シード $s$ について、5 つの水準の $\log c_s(N)$ を $\log N$ に最小二乗で直線あてはめした傾き $b_s$ を求め、$\Delta_A = 1 - \frac{1}{n} \sum_s b_s$($n$ は実験 A のシード数。正を期待)とする。$\Delta_A > 2\sigma_A$ なら支持、$\Delta_A < -2\sigma_A$ なら反証、それ以外は判定不能。

**前提条件**: P1(A)。

**解釈の注意**: 小さい $N$ の費用が探索の幅の格子の下限に張り付くと、$b$ が小さく見積もられ、対比量が仮説に有利な向きに偏る(P1(A)で検出する)。判定は測った $N$ の範囲(16 倍)のべき指数で、漸近の主張ではない。$\sigma_A$ の見込みの上限は約 0.016(閾値は約 0.032)で、設計は見直さず本番に進んだ(付録 C.4)。

#### 実験 B: HNSW と転置ファイルの比較

**検証すること**: 最大の $N$($N = N_{\max}$)で、目標の recall 0.9 での費用が、HNSW の方が転置ファイルより小さいか。同じシードの同じ部分集合で、HNSW は実験 A の設定のまま調整せず、転置ファイルはリスト数 5 点のそれぞれを掃引して、費用が最も小さいものを値にする。

**判定基準**: $\Delta_B = \frac{1}{n} \sum_s ( \log c_{1,s} - \log c_{2,s} )$($c_{1,s}$ は転置ファイルの、$c_{2,s}$ は HNSW の $N = N_{\max}$ での、目標の recall での費用。正を期待)。$\Delta_B > 2\sigma_B$ なら支持、$\Delta_B < -2\sigma_B$ なら反証、それ以外は判定不能。

**前提条件**: P0(B)、P1(B)。

**解釈の注意**: 転置ファイルは最小を選ぶので下側(有利な側)に偏り、HNSW は $M = 5$ を調整しないので不利な側にありうる。どちらも対比量を仮説(HNSW が有利)に不利な向き(負)に偏らせるので、**支持は偏りがあっても成り立つ結果** として読み、反証は HNSW の費用が大きいことと調整の差を区別できない。距離計算の回数の比較で、壁時計時間の比較ではない。$\sigma_B$ の見込みの上限は約 0.048(閾値は約 0.095)で、設計は見直さず本番に進んだ(付録 C.4)。

#### 実験 C: Product Quantization の非対称距離計算と対称距離計算

**検証すること**: 同じ符号帳($m = 32$、$k^* = 256$。$N = N_{\max}$ の部分集合の全ベクトルで学習)で、非対称距離計算の recall が対称距離計算より高いか。索引は全件を走査し、再採点はしない。

**判定基準**: $\Delta_C = \frac{1}{n} \sum_s ( \mathrm{recall}_s^{\mathrm{asymmetric}} - \mathrm{recall}_s^{\mathrm{symmetric}} )$(全探索の上位 10 件との一致率の、query についての平均の差。正を期待)。$\Delta_C > 2\sigma_C$ なら支持、$\Delta_C < -2\sigma_C$ なら反証、それ以外は判定不能。

**前提条件**: P2(C)。

**解釈の注意**: 符号帳が passage の分布で学習され、query(長さ 32 トークン)の分布と異なると、query の量子化の誤差 $\mathbb{E}\lVert e_x \rVert^2$ が passage の $D$ より大きくなり、対称距離計算が理論以上に悪くなる。これは対比量を **仮説に有利な向きに偏らせる**。診断量で $\mathbb{E}\lVert e_x \rVert^2$ と $D$ を並べて読む。$\sigma_C$ の見込みの上限は約 0.0092(閾値は約 0.018)(付録 C.4)。

#### 実験 D: cross-encoder の相互作用の効果

**検証すること**: 起点・学習データ・負例・損失の形・学習ステップ数を揃えたとき、cross-encoder による並べ替え(D1)が、dual encoder による並べ替え(D2)より、並べ替えの Recall@10 が高いか。どちらも 008 の`main`から始め、同じ(query、正例、困難な負例 7 個)の組を同じ順序で見る。学習率は条件ごとに較正する。

**判定基準**: $\Delta_D = \frac{1}{n} \sum_s ( R_s(\mathrm{D1}) - R_s(\mathrm{D2}) )$($R_s(c)$ はシード $s$ の条件 $c$ の並べ替えの Recall@10。正を期待)。$\Delta_D > 2\sigma_D$ なら支持、$\Delta_D < -2\sigma_D$ なら反証、それ以外は判定不能。

**前提条件**: P0(D1・D2)、P1(D1・D2)、P2(D2)、P3。

**解釈の注意**: cross-encoder の列は dual encoder の passage 側の入力より長く、**計算量は揃っていない**。また、新しいヘッドと、008 が見たことのない区切り・終端のトークンを使うので、小さい学習量では立ち上がりが遅く、**対比量が負の向きに偏りうる**。「並べ替えを足すと上がる」ことは判定の対象にしない。検出力の事前確認では、評価の変動の項の範囲が約 0.006〜0.021(閾値は約 0.012〜0.042)で、シード間の項が加わる。想定される効果(coverage − 並べ替えなしの Recall@10 は 0.19 程度)に比べて上限は無視できない大きさだが、検出力を上げる手段が限られるため、設計は見直さず本番に進んだ(付録 C.4)。

#### 実験 E: 困難な負例の効果

**検証すること**: 第 1 段の上位から採掘した困難な負例で学習した cross-encoder(E1 = D1)が、ランダムな負例で学習した cross-encoder(E2)より、並べ替えの Recall@10 が高いか。負例の数(7 個)・学習ステップ数・損失の形・query と正例の系列は揃える。

**判定基準**: $\Delta_E = \frac{1}{n} \sum_s ( R_s(\mathrm{E1}) - R_s(\mathrm{E2}) )$($n$ は D1 と E2 に共通のシード数。正を期待)。$\Delta_E > 2\sigma_E$ なら支持、$\Delta_E < -2\sigma_E$ なら反証、それ以外は判定不能。

**前提条件**: P0(D1・E2)、P1(D1・E2)、P2(E2)、P3。

**解釈の注意**: E2 の負例は多くが第 1 段の上位 50 件の外にあり、正例(上位 50 件の中)を第 1 段のスコアの高さで区別できるので、推論時には役に立たない区別を学びうる。この寄与は対比量を **仮説に有利な向き(正)に偏らせうる**。一方、偽の負例(採掘した候補のうち、実際には関連する別の記事の passage)は E1 の学習を妨げ、仮説に不利な向き(負)に偏らせる。反証は、困難な負例が劣ることと偽の負例の影響を区別できない。検出力の事前確認は実験 D と同じ(付録 C.4)。

#### 7.12.1 問い 1: なぜ前提条件が崩れたか

**観察されたこと**(セル出力の値):

1. D1 の最後の区間の訓練損失は 5 シードで 2.059〜2.078(平均 2.072)で、一様な予測の損失 $\ln 8 = 2.0794$ との差が 0.001〜0.020 しかなく、学習前のモデルの同じ組での損失との比は 0.976〜0.993(7.2 節)。
2. D1 の候補 50 件のスコアの標準偏差の中央値は 0.0457〜0.1197 で、E2(1.2114〜1.3394)の 10 分の 1 以下。ランダムな候補の中での指標も偶然の水準(Recall@10 0.2156。7.6・7.7 節)。
3. 同じ構造の E2 は、同じステップ数・同じ query と正例で、訓練損失が 0.437〜0.657(平均 0.547)まで下がった。D2 は平均 1.868(学習前との比 0.852〜0.903)。
4. 較正で D1 の学習率を 256 倍の範囲で変えても、最後の区間の訓練損失は 2.056〜2.082(学習前の 2.127 に対する比 0.967〜0.979)にとどまった(7.1 節)。

**原因の候補 1: 学習量(見た query の数・ステップ数)が足りない**

- 根拠: 本番の学習は使える query の 0.208 エポックで、D1 の損失は $\ln 8$ の付近に留まった(観察 1)。ただし、学習率を 256 倍の範囲で変えても下がらず(観察 4)、E2 は同じステップ数で下がった(観察 3)ので、ステップ数だけでは説明しにくい。

**原因の候補 2: 課題が難しい(正例も負例も第 1 段の上位 50 件の中にあり、第 1 段が使った手がかりでは区別できない)**

**原因の候補 3: 学習率の較正の選び方(単一シードの平均逆順位)**

- 根拠: E2 は易しい区別を学んだ(訓練損失 0.437〜0.657、ランダムな候補の中の Recall@10 0.6644)が、上位 50 件の並べ替えの Recall@10 は 0.1762 で、並べ替えなしの 0.2199 より低い。較正の query での増分は +0.0525・+0.0525・+0.0228・-0.0148・-0.0251 と符号がそろわず、標準偏差 0.0213 のうちシード間の項(0.0163)がブートストラップの項(0.0137)より大きい。学習前のモデルの Recall@10 のシードごとの値は印字しておらず、増分のばらつきへの寄与は分からない(根拠となる数値はない)。
- 確かめる方法: 候補 2 の (1) と同じ測定。ランダムな負例と困難な負例を混ぜた学習で、上位 50 件の中での増分が安定するかを見る。E2 のシード数を増やす。

**原因の候補 7: 成分 (b) の閾値の下限が、E2 の増分に対して高い**

- 根拠: 成分 (b) は、増分のシード平均が $\sigma_g$ の 2 倍以上であることを要求し、$\sigma_g$ はシード数を増やしても、ブートストラップの項 $\sigma_{\mathrm{boot}}$ 以下にならない。E2 の項は 0.0137 なので、増分のシード平均が 2 × 0.0137 = 0.0274 以上でなければ成立せず、E2 の増分のシード平均 +0.0176 はそれより小さい。パイロットの E2 の増分 +0.0251 も、単一シードの項 0.0176 の 2 倍(0.0352)より小さかった。D2 は、項 0.0070 から下限 0.0140 で、増分 +0.0180 で成立した。
- 確かめる方法: 較正の query の数を増やした場合の閾値の下限を、E2 の増分と比べる(評価の変動の項から計算でき、学習は不要)。この候補は、成分 (a) の成否とは独立に、成分 (b) の成立を難しくしている。

#### 7.12.2 問い 2: 判定関数の参考値が、なぜその向きになったか

参考値を結論として扱わずに、値の向きの説明の候補だけを述べる。

- **実験 D の参考値 $\Delta_D = -0.0625$**(D1 が D2 より低い)。観察: $d_s$ は 5 シードすべてで負で、R(D1) の平均は 0.1712、R(D2) は 0.2337(D1 は並べ替えなしの 0.2199 を 0.0487 下回り、D2 は 0.0138 上回った)。解釈の候補: (i)D1 の値が、学習が立ち上がらなかったモデルの値であること(スコアがほぼ定数のモデルの並べ替えは、第 1 段の順位より情報の少ない順位になりうる)。(ii)6.1 節で宣言した、cross-encoder の立ち上がりが遅いことによる負の向きの偏り(候補 4 と重なり、分離していない)。この向きは、cross-encoder の構造の優劣を示さない。
- **実験 E の参考値 $\Delta_E = -0.0050$**(絶対値が閾値以内)。観察: R(E1) の平均 0.1712 と R(E2) の平均 0.1762 は近く、どちらも並べ替えなしの 0.2199 より低い。解釈の候補: (i)E1 = D1 が学習できていないので E1 の値は学習前に近く、E2 は易しい区別を学んだが上位 50 件の並べ替えには効かず(候補 6)、ともに第 1 段より低い近い水準にとどまったため、差が小さく出た。(ii)偽の負例が E1 の学習を妨げうる(候補 5)。**負例の種類の効果は、この結果から読めない。**
- 確かめる方法(D・E 共通): D1 の学習が成立する設計に直したうえで、判定基準を変えずに実験 D・E をやり直す。先に、D1 の並べ替えの順位が第 1 段の順位とどの程度対応するかと、候補 2 の (1) の測定(E2 の損失の低下の原因)を調べる。

#### 7.12.3 教訓(次のトピックの設計に持ち越せる一般的な事項)

1. 前提条件の閾値を決めるパイロットは、本番で選ばれうる学習率(較正の格子の端を含む)でも行う(余裕が小さかった D1 が、中心の 4 倍の学習率で、5 シード中 2 シードで不成立になった)。
2. 較正の選択(単一シードの平均逆順位)は、差が標準偏差より小さいことがあり、学習の成立の余裕と整合しない学習率を選びうる。選択の規則に余裕を含めるか、差が標準偏差以内のときの規則を、本番の前に宣言する(候補 3)。
3. 前提条件の閾値が評価の query の数で決まる下限(ブートストラップの項)を持つとき、基準の条件の想定される増分がその下限を超えるかを、本番の前に確かめる(候補 7。学習は不要)。
4. 較正の段階で、学習の成立の余裕が全格子点で小さい条件を検出したときの扱いを、本番の前に宣言する。
5. 診断量(候補 50 件のスコアの標準偏差、ランダムな候補の中での指標)は、学習が進まない状態と、易しい区別だけを学んだ状態の区別に役立った。判定とは別の診断として残す。
6. 公開の条件を事前に宣言しておいたことで、並べ替えで第 1 段より悪くなるモデルは公開されなかった。
7. 困難な負例だけで学習を始める設計は、学習が進まない状態に陥りうる。易しい負例を混ぜる、または段階的に難しくする設計を、条件の 1 つとして用意する(検証しておらず、候補である)。
8. 損失が下がることと、下流の指標が基準(何もしない場合)を上回ることは別である($T = 8192$ で最後の区間の訓練損失は 1.9610 まで下がったが、Recall@10 0.2292 は並べ替えなしの 0.2725 を下回った)。再実行の前のパイロットでは、下流の指標も分岐の条件に含めるかを検討する。

### 7.13 制約と一般化の範囲

- **コーパスとモデル**: 1 つのコーパス(Wikipedia 英語の 9,470 記事。リスト系の記事が 30.2%、記事の長さの中央値が 14,267 トークン)、1 つの第 1 段(024 のチェックポイント。凍結)、1 つの起点(008 の`main`)。関連性は「同じ記事の他の passage」で、別の記事の関連する passage は負例として扱われる。他のコーパス・他の言語には一般化しない。
- **学習量**: $T = 1024$ は使える query の 0.208 エポックで、学習が飽和した状態ではない。
- **近似最近傍探索の設定**: HNSW は $M = 5$、$efConstruction = 100$ の 1 設定(大きい $M$ では、費用もべき指数も異なりうる)、転置ファイルはリスト数 5 点から費用が最小のものを選んだ、Product Quantization は $m = 32$、$k^* = 256$ の 1 設定。実験 A・B の結論はこの設定に限る。費用は距離計算の回数で、壁時計時間ではなく、HNSW の構築の費用を含まない。
- **評価の query の数とシード数**: 近似最近傍探索 890 個・3 シード、並べ替え 1,446 個・5 シード、較正 877 個。ブートストラップは記事を単位とする。
- **実験 D・E**: 前提不成立で、仮説に関する情報を得ていない。事後的な解釈(7.12 節)は、検証していない候補である。実験 F は、D1 のシード 0 の 1 つのモデルの観察で、ブートストラップは行っていない。
- **再実行に向けたパイロット**(7.11 節): D1 の単一の条件の 1 シードで、D2・E2 とは比べていない。Hub へのアップロードは行っておらず、D1 のシード 0 の重みは後続のアプリの入力として使えない。
