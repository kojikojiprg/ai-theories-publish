### 7.3 実験 A: HNSW の探索の費用の件数への依存性

**判定**(6.8 節の出力): $\Delta_A = +0.6657$。シードごとのべき指数は $b_s$ = 0.3342・0.3340・0.3346(平均 $\bar{b} = 0.3343$。$\Delta_A = 1 - \bar{b}$)。標準偏差 $\sigma_A = 0.0102$(シード間の項 0.0002、ブートストラップの項 0.0102)、閾値 $2\sigma_A = 0.0204$。
$\Delta_A > 2\sigma_A$(閾値の 0.6657 ÷ 0.0204 = 約 33 倍)なので、**事前に宣言した基準で支持** である。前提条件 P1(A)は成立した(7.2 節)。
事前の見込み(6.1 節の検出力の事前確認)は、$\sigma_A$ の上限が約 0.016、下限が約 0.003 で、観測の 0.0102 はその範囲内だった。標準偏差のほとんどは、評価の query が有限であることによるブートストラップの項で、シード間の項は 0.0002 と小さい。

**目標の recall での費用**(1 query あたりの距離計算の回数。シード平均の幾何平均。query 890 個):

| $N$ | 4,096 | 8,192 | 16,384 | 32,768 | 65,536 |
|---|---|---|---|---|---|
| 費用 $c$ | 156.8 | 197.3 | 244.5 | 308.4 | 399.4 |
| 全探索の費用 $N$ との比 $c / N$ | 0.0383 | 0.0241 | 0.0149 | 0.0094 | 0.0061 |

- $N$ が 16 倍になると費用は 399.4 ÷ 156.8 = 2.55 倍で、べき指数 0.334 から計算した $16^{0.334} = 2.52$ に近い。$N$ が 2 倍になるごとに、費用は約 26% 増える($2^{0.334} = 1.26$)。
- 全探索との比は $N$ とともに小さくなり、$N = 65{,}536$ で 0.0061、すなわち全探索の約 164 分の 1(65,536 ÷ 399.4)である。
- 費用の対数のべき乗則へのあてはめの残差(二乗平均平方根)は、シードごとに 0.0129・0.0121・0.0156 だった。

**診断量(判定なし)**:

- **階層の効果**(シード 0): 最下層だけをランダムな入口から探索したときの目標の recall での費用は、階層ありの費用の **1.01〜1.06 倍** だった($N = 4{,}096$: 161.0 対 156.9(1.03 倍)、8,192: 208.9 対 202.4(1.03 倍)、16,384: 255.3 対 252.0(1.01 倍)、32,768: 327.8 対 310.3(1.06 倍)、65,536: 414.6 対 403.5(1.03 倍))。
  階層を使わなくても、費用は階層ありの 6% 以内の増加にとどまった。これは、高次元のデータで階層が対数の計算量をもたらさず、階層を持たない近傍グラフと同程度の性能になるという報告(Lin & Zhao [8]、Munyampirwa ら [9])と整合する観察である(本トピックの埋め込みは $d = 256$)。
  ただし、シード 0 の 1 回の測定で、最下層だけの探索のばらつきは評価しておらず、判定の対象でもない。表の階層ありの費用はシード 0 の値で、上の 3 シードの幾何平均とは少し異なる($N = 8{,}192$ で 202.4 と 197.3)。
- **構築の距離計算**(シード 0、累積): $N = 4{,}096$ で 2,453,609 回、8,192 で 5,239,088 回、16,384 で 11,070,203 回、32,768 で 23,232,288 回、65,536 で 48,670,745 回。$N$ が 16 倍で 48,670,745 ÷ 2,453,609 = 19.8 倍で、$N$ に対して超線形に増えた(べき指数は約 1.08)。
- **層の大きさ**($N = 65{,}536$、シード 0): 層 0 から順に 65,536・13,221・2,575・508・108・17・4。層 1 以上は 13,221 個で、3.3.2 節の式 $N M^{-1} = 65{,}536 / 5 = 13{,}107$ に近い。
- **壁時計時間**(観察。判定には使わない): HNSW の構築はシード 0・1・2 で 283.2・286.0・280.0 秒。

**判定が確かめた範囲**: 測った 16 倍の範囲($N = 4{,}096$〜$65{,}536$)・3 シード・$M = 5$、$efConstruction = 100$ の 1 設定で、費用が $N$ に比例せず($b < 1$)、$N^{0.334}$ にほぼ比例して増えたことである。この判定は、べき乗則 $c \propto N^{b}$ のあてはめの傾きが 1 より小さいかを見るもので、**漸近の主張ではない**。
測った範囲の外(より大きい $N$)で、$b$ がこの値のまま続くのか、費用の増え方がさらに緩やかになる(対数的な増加に近づく)のかは、この実験からは言えない。
また、べき乗則と対数的な増加(たとえば $\log N$ の冪)を区別する判定は設けていない。参考として、費用 $c$ の隣り合う水準の差は +40.5・+47.2・+63.9・+91.0(上の表の値の差)と後ろの水準ほど大きく、費用が $\log N$ に比例するなら差は一定になるので、この範囲の増え方は $\log N$ への比例の形ではない。
ただし、この差のばらつきは評価しておらず、判定にも診断量にも含めていないので、増え方の形を区別できたとは書かない。$M$ を大きくした設定では、費用もべき指数も異なりうる(測っていない)。

**距離の誤差の診断量**(判定なし。query と passage の一様ランダムな 20,000 組の平均、シード平均):

| 量 | 非対称距離計算 | 対称距離計算 |
|---|---|---|
| 推定の二乗距離の偏り(推定 - 真の値の平均)の実測 | -0.1017 | -0.3157 |
| 理論の偏り(3.4 節) | $-D = -0.1014$ | $-(\mathbb{E}\lVert e_x \rVert^2 + D) = -0.2763$ |
| 実測 - 理論 | -0.0003 | -0.0394 |
| 平均二乗誤差 | 0.01541 | 0.11299(非対称の 7.33 倍) |

量子化の平均二乗誤差は $D = 0.1014$、query の量子化の誤差は $\mathbb{E}\lVert e_x \rVert^2 = 0.1749$($D$ の 1.73 倍)だった。1 ベクトルあたり 32 バイト(元は 1,024 バイトで、圧縮率 32 倍)。1 query あたりの費用は、
非対称距離計算が参照表の作成 8,192 回と表引き 2,097,152 回(= 65,536 × 32)、対称距離計算が query の量子化 8,192 回と表引き 2,097,152 回。表引きの 1 回は全次元の距離計算より軽く、HNSW・転置ファイルの距離計算の回数と直接は比べられない。

**事後的な解釈(検証済みの結論ではない)**: 非対称距離計算の偏りの実測は理論の $-D$ と一致した(差 -0.0003)。一方、**対称距離計算の偏りの実測 -0.3157 は、理論の -0.2763 より 0.0394 だけ負の側にあり**(実測は理論の 1.14 倍。0.3157 ÷ 0.2763)、一致しなかった。
この差の原因は確かめていない。3.4 節の対称距離計算の偏りの式が置いた仮定は、次のとおりである。

1. 誤差 $e_x = x - q(x)$ と $e_y = y - q(y)$ が、それぞれの領域(符号語)を決めると平均 0 であること(符号語が領域のベクトルの平均であること)。符号帳は passage で学習した 15 回の k-means の結果で、収束していることも、query の領域内の平均が符号語に一致することも、保証されていない。
2. $e_x$ と $e_y$ が独立であること(式の第 3 項の期待値が $\mathbb{E}\lVert e_x \rVert^2 + \mathbb{E}\lVert e_y \rVert^2$ になる条件)。
3. 符号語どうしの差 $q(x) - q(y)$ と誤差 $e_x - e_y$ の内積の期待値が 0 であること(第 2 項の期待値が 0 になる条件)。

非対称距離計算の導出が置く仮定は、$y$ の誤差 $e_y$ の平均が 0 で、$x - q(y)$ と独立であること(上の 1 の $y$ の側)だけで、実測はこの側で理論と一致した。対称距離計算の導出は、これに加えて $x$ の誤差 $e_x$ に関する仮定(上の 1〜3 のうち $x$ に関わる部分)を置く。
したがって、差はそれらの仮定が成り立たないことに由来する可能性があるが、項ごとの測定をしておらず、原因は特定していない。また、診断量の組は一様ランダムな 20,000 組で、検索で問題になる近い組ではない。近い組では、$e_x$ と $e_y$ の相関が異なりうる(測っていない)。
6.1 節の宣言のとおり、query の量子化の誤差が passage の $D$ より大きい(1.73 倍)ことは、対比量 $\Delta_C$ を仮説に有利な向きに偏らせうるが、その寄与の大きさは分離していない。

##### 原因の候補 6: E2 の損失の低下が、推論時の候補(第 1 段の上位 50 件)を区別する力に転移しない(E2 の成分 (b) の不成立)

- **根拠**: E2 は易しい区別を学んだ(訓練損失 0.437〜0.657、ランダムな候補の中の Recall@10 0.6644(偶然の水準 0.2)・Recall@1 0.1904(偶然の水準 0.02))。一方、第 1 段の上位 50 件の並べ替えの Recall@10 は 0.1762 で、並べ替えなしの 0.2199 より低い。
  較正の query での Recall@10 の増分(学習後 - 学習前)は、シードごとに +0.0525・+0.0525・+0.0228・-0.0148・-0.0251 と符号がそろわない。標準偏差 0.0213 のうち、シード間の項(0.0163)が、ブートストラップの項(0.0137)より大きい。
  学習前のモデルの Recall@10 のシードごとの値は印字していないので、増分のばらつきのうち学習前の値のばらつきの寄与は分からない(根拠となる数値はない)。
- **確かめる方法**: 候補 2 の (1) と同じ測定。ランダムな負例と困難な負例を混ぜた学習で、上位 50 件の中での増分が安定するかを見る。E2 のシード数を増やす。

##### 原因の候補 7: 成分 (b) の閾値の下限が、E2 の増分に対して高い(較正の query の数で決まる下限)

- **根拠**: 成分 (b) は、増分のシード平均が標準偏差 $\sigma_g$ の 2 倍以上であることを要求する(6.1 節)。$\sigma_g = \sqrt{\mathrm{Var}_s(g_s)/n + \sigma_{\mathrm{boot}}^2}$ は、シード数 $n$ を増やしても、ブートストラップの項 $\sigma_{\mathrm{boot}}$ 以下にはならない。
  E2 のブートストラップの項は 0.0137 なので、この項が観測値のままなら、シード数によらず、増分のシード平均が 2 × 0.0137 = 0.0274 以上でなければ成立しない。E2 の増分のシード平均は +0.0176 で、それより小さい。パイロットの E2 の増分 +0.0251 も、単一シードのブートストラップの項 0.0176 の 2 倍(0.0352)より小さかった(6.2.6.2 節)。
  D2 は、ブートストラップの項 0.0070 から閾値の下限が 0.0140 で、増分 +0.0180 で成立した。
- **確かめる方法**: 較正の query の数(検証用の記事 100 本、877 個)を増やした場合の閾値の下限を、E2 の増分と比べる(評価の変動の項から計算でき、学習は不要)。
- この候補は、E2 の学習が実際に進んでいるか(成分 (a) は成立している)とは独立に、成分 (b) の成立を難しくしている。

#### 7.11.2 問い 2: 判定関数の参考値が、なぜその向きになったか

この問いは、参考値を結論として扱わずに、値の向きの説明の候補だけを述べる。

**実験 D の参考値 $\Delta_D = -0.0625$(D1 が D2 より低い。絶対値が閾値 0.0168 を超える)**:

- **観察**: $d_s$ は 5 シードすべてで負(-0.0526〜-0.0761)。R(D1) の平均は 0.1712、R(D2) は 0.2337で、D1 は並べ替えなしの 0.2199 を 0.0487 下回り、D2 は 0.0138 上回った。D1 のスコアはほぼ定数で(標準偏差 0.0457〜0.1197)、ランダムな候補の中の指標も偶然の水準だった。
- **解釈の候補 (i)**: D1 の値が、学習が立ち上がらなかったモデルの値であること。スコアがほぼ定数のモデルの並べ替えは、第 1 段の順位より情報の少ない順位になりうる。第 1 段の上位 10 件にいた正例は、並べ替えで上位 10 件の外に出やすい。
  確かめるには、D1 の並べ替えの順位が第 1 段の順位とどの程度対応するかを測る(未実施)。
- **解釈の候補 (ii)**: 6.1 節で宣言した、対比量を負の向きに偏らせうる要因(cross-encoder は新しいヘッドと、008 が見たことのないトークンを使うので、小さい学習量では立ち上がりが遅い。計算量が揃っていない)。本番の $T$ は最大の 1024 だったので、$T$ が小さい計画による偏りの拡大はない。
  この要因の寄与は、D1 が学習できなかった理由の一部(候補 4)と重なり、分離していない。
- **D2 について**: D2 は並べ替えなしを 0.0138 上回り、小さいながら学習が進んだ(最後の区間の損失 1.868、学習前との比 0.852〜0.903)。D2 が D1 より学習が進んだこと(観察)は、参考値が負になる向きと整合する。
- **この向きは、cross-encoder の構造の優劣を示さない。** D1 の学習が成立していた場合に向きが変わるかは、この実験からは分からない。
- **確かめる方法**: D1 の学習が成立する設計(7.11.1 節の確かめる方法)に直したうえで、判定基準を変えずに、実験 D をやり直す。

**実験 E の参考値 $\Delta_E = -0.0050$(絶対値が閾値 0.0151 以内)**:

- **観察**: R(E1) の平均 0.1712 と R(E2) の平均 0.1762 は近く、5 シードの $d_s$ は +0.0007・-0.0021・-0.0014・-0.0166・-0.0055 と、小さく、符号がそろわない。どちらも並べ替えなしの 0.2199 より低い。
- **解釈の候補 (i)**: E1 = D1 が学習できていない(7.11.1 節)ので、E1 の値は学習前に近い水準にあること。E2 は易しい区別を学んだが、上位 50 件の並べ替えには効かず(0.1762 < 0.2199。候補 6)、E1 と同じ程度の、並べ替えなしより低い水準にとどまった。
  2 つの条件がともに「第 1 段より低い、近い水準」にあるので、差が小さく出た可能性がある。
- **解釈の候補 (ii)**: 6.1 節で宣言した、E2 が第 1 段のスコアの高さという手がかりを学ぶ寄与は、対比量を仮説に有利な向き(正)に偏らせうる。実際には、E2 の値が E1 より閾値を超えて大きくなることはなかった(参考値は閾値以内)。
  偽の負例は E1 の学習を妨げうる(候補 5。測っていない)。
- **負例の種類の効果は、この結果から読めない。** E1 が学習できていない状態で比べているためである。
- **確かめる方法**: D1 の学習が成立する設計に直したうえで、判定基準を変えずに、実験 E をやり直す。候補 2 の (1) の測定で、E2 の損失の低下の原因を先に調べる。

#### 7.11.3 教訓(次のトピックの設計に持ち越せる一般的な事項)

1. 前提条件の閾値を決めるパイロットは、本番で選ばれうる学習率(較正の格子の端を含む)でも行う。025 のパイロットは中心の学習率の 1 シードで、そこで余裕が小さかった D1 が、中心の 4 倍の学習率で、5 シード中 2 シードで不成立になった(6.2.6.4 節)。
   全実験の基準に入る条件の学習の成立は、複数のシード・複数の学習率で確かめる。
2. 較正の選択(単一シードの平均逆順位)は、差がブートストラップの標準偏差より小さいことがあり、学習の成立の余裕と整合しない学習率を選びうる(候補 3)。選択の規則に、学習の成立の余裕(差の平均 / 標準誤差など)を含める、
   または差が標準偏差以内のときの規則を、本番の前に宣言する。
3. 前提条件の閾値が、評価の query の数だけで決まる下限(ブートストラップの項)を持つとき、基準の条件の想定される増分がその下限を超えるかを、本番の前に、評価の変動の項から確かめる(候補 7。学習は不要)。
4. 較正の段階で、学習の成立の余裕が全格子点で小さい条件(025 の D1 は、5 つの学習率で最後の区間の損失が 2.056〜2.082)を検出したときの扱いを、本番の前に宣言する。本番は 1 回で完結させるので、較正の出力を見てからの判断は事前の規則として決めておく必要がある。
5. 診断量(候補 50 件のスコアの標準偏差、ランダムな候補の中での指標)は、学習が進まない状態と、易しい区別だけを学んだ状態を区別するのに役立った。判定とは別の診断として残す。
6. 公開の条件(判定ではない品質の条件)を事前に宣言しておいたことで、並べ替えで第 1 段より悪くなるモデルは公開されなかった。公開するアーティファクトには、事前に宣言した品質の条件を置く。
7. 困難な負例だけで学習を始める設計は、学習が進まない状態に陥りうる(候補 1・2)。易しい負例を混ぜる、または段階的に難しくする設計を、条件の 1 つとして用意する(025 では検証しておらず、候補である)。

### 7.12 制約と一般化の範囲

- **コーパス**: 1 つのコーパス(Wikipedia 英語の 9,470 記事。リスト系の記事が 30.2%、記事の長さの中央値が 14,267 トークンと長い記事が多い)で、記事ごとに最大 12 個の passage を等間隔に選んだ(passage 94,486 個、passage を切り出せた記事は 9,158 本で、1 記事あたり平均 10.32 個)。
  関連性は「同じ記事の他の passage」で、別の記事の関連する passage は負例として扱われる。他のコーパス・他の長さの passage・他の言語には一般化しない。
- **第 1 段と起点のモデル**: 第 1 段は 024 の 1 つのチェックポイント(凍結)、cross-encoder と dual encoder の起点は 008 の`main`の 1 つのチェックポイント。実験 D・E の値は、それらから始めた場合に限る(いずれも前提不成立)。
- **学習量**: 本番の $T = 1024$ は、使える query の 0.208 エポックで、学習が飽和した状態ではない。学習を続けた場合の D1・D2・E2 の値や順位は、この実験からは言えない。
- **近似最近傍探索の設定**: HNSW は $M = 5$(原論文の妥当な範囲 5〜48 の下限。格子が目標の recall を挟むように選んだ。6.2.2 節)、$efConstruction = 100$、探索の幅の格子は公比 $2^{1/3}$ で、調整していない。大きい $M$ では、費用もべき指数も異なりうる(測っていない)。
  実験 A・B の結論はこの設定に限る。転置ファイルは、リスト数 $\sqrt{N}$ の 1/2〜8 倍の 5 点(公比 2)から費用が最小のものを選んだ(格子の点の間は探索していない)。k-means は 20 回の反復で、初期化は点の集合からの無作為な選択。
  Product Quantization は $m = 32$、$k^* = 256$ の 1 設定(符号長は、6.2.3 節で $m = 16, 32, 64$ を $N = 32{,}768$ の 1 シードで見ただけ)。
- **評価の query の数とシード数**: 近似最近傍探索 890 個、並べ替え 1,446 個、実験 F 594 個、較正 877 個。同じ記事の query は互いに独立でないので、ブートストラップは記事を単位とした。実験 A・B・C の標準偏差はブートストラップの項が支配的で(7.3〜7.5 節)、
  シード数を 5 から 3 に削っても閾値はほとんど変わらない。実験 D・E は 5 シード。
- **費用の定義**: 距離計算の回数で、壁時計時間ではない。HNSW の構築の費用を含まない(7.4 節)。Product Quantization の表引きは、全次元の距離計算と単位が異なる(7.5 節)。
- **実験 D・E**: 前提不成立で、仮説に関する情報を得ていない。cross-encoder の優劣も、困難な負例の効果も、この実験からは言えない。事後的な解釈(7.11 節)は、検証していない候補である。
- **実験 F**: 1 つのモデル(D1 のシード 0。D1 は実験 D・E で前提条件が不成立の条件)・1 つの部分集合($N = 65{,}536$、シード 0)・594 query の観察で、ブートストラップは行っていない。関連性は部分集合の中での同じ記事の passage(正解の数の中央値 7)で、
  実験 D・E(コーパス全体。中央値 11)と Recall@10 の絶対値を比べない。
- **Hub へのアップロード**: 行っていない(7.10 節)。D1 のシード 0 の重みは保存していないので、後続のアプリ(`apps/`)の入力としては使えない。
