### 7.3 実験 A(微調整なしでの外挿)

**判定(事前宣言した基準による)**: **支持。** 評価長 $4L$ の位置 $[L, 4L)$ で、$\Delta_A = b_{\mathrm{interp}} - b_{\mathrm{yarn}} = +0.1587$、
$\sigma_A = 0.0049$(記事を単位とするクラスタブートストラップ)で、$\Delta_A - 2\sigma_A = +0.1490 > 0$ である。推論時にだけ適用した
YaRN は、位置補間より学習長を超える位置の bits-per-byte が低い。旧基準(評価窓を単位とするブートストラップ)の標準偏差は
0.0026 で、記事を単位にすると約 1.9 倍になったが、判定は変わらない。記事ごとの差は 12 本すべてで正($+0.1337$〜$+0.1764$)で、
1 本の記事が対比量を支配してはいない。

**診断量**:

- 同じ対比量は $2L$ で $+0.0624$($\sigma = 0.0030$)、$8L$ で $+0.2585$($\sigma = 0.0084$)で、評価長(倍率 $s$)とともに大きくなった。
- 手法ごとの bits-per-byte($[0, L)$ / 学習長を超える位置 $[L, sL)$、$s$ は評価長 $/ L$):

  | 手法 | $2L$ | $4L$ | $8L$ |
  |---|---|---|---|
  | スケーリングなし | 1.6552 / 1.8147 | 1.6552 / 1.9914 | 1.6552 / 2.1466 |
  | 位置補間 | 1.7265 / 1.7290 | 1.8419 / 1.8570 | 1.9523 / 1.9862 |
  | NTK-aware | 1.6559 / 1.6813 | 1.6608 / 1.7531 | 1.6698 / 1.8810 |
  | NTK-by-parts | 1.6661 / 1.6681 | 1.6926 / 1.7056 | 1.7237 / 1.7478 |
  | YaRN | 1.6676 / 1.6666 | 1.6951 / 1.6983 | 1.7275 / 1.7277 |

  スケーリングなしは、$[0, L)$ の 1.6552 に対して学習長を超える位置で 1.8147($2L$)から 2.1466($8L$)まで悪化した(3.2 節の
  「学習長を超えると壊れる」)。位置補間は学習長を超える位置の悪化は小さいが、$[0, L)$ も $s$ とともに 1.7265 から 1.9523 まで
  悪化した。YaRN は学習長を超える位置で全ての評価長で最も低かった。
- Attention のエントロピー(評価長 $8L$、$s = 8$、層・ヘッド・窓で平均): Query の位置 $[L/2, L)$ と $[4L, 8L)$ の平均は、
  スケーリングなし 2.0973 → 4.0129、NTK-by-parts 2.7479 → 3.7003、YaRN 1.9767 → 2.6161 nats だった。

**事後的な解釈(検証していない)**:

- YaRN と NTK-by-parts は周波数が同じで、温度の補正の有無だけが異なる。学習長を超える位置では YaRN が $4L$ で 0.0073、$8L$ で
  0.0201 低く、倍率が大きいほど温度の補正が効いているように見える。一方、$[0, L)$ では YaRN が $4L$ で 0.0025、$8L$ で 0.0038
  高く、温度の補正は学習長以内ではわずかに不利に働いている。
- エントロピーでは、周波数を補間しただけの NTK-by-parts は学習長以内の位置でもスケーリングなしよりエントロピーが高く
  (2.7479 対 2.0973)、Attention の分布が平らになっている。温度の補正を加えた YaRN はこれをスケーリングなしに近い値(1.9767)まで
  戻し、$[4L, 8L)$ でもエントロピーの増加が 3 手法で最も小さかった。3.6 節の「logits を $1/t$ 倍して鋭くする」という温度の補正の
  解釈と整合するが、エントロピーの低さと bits-per-byte の改善の因果は確かめていない。
- 診断用の NTK-by-parts(周波数は YaRN と同じで、温度の補正だけがない)を間に置くと、評価長 $4L$ の位置 $[L, 4L)$ の
  $\Delta_A = 0.1587$ は、位置補間 − NTK-by-parts $= 1.8570 - 1.7056 = 0.1514$(周波数の違いの寄与。5.5 節の表のとおり、この
  モデルでは部分空間 0〜6 だけにある違い)と、NTK-by-parts − YaRN $= 1.7056 - 1.6983 = 0.0073$(温度の補正の寄与)に分解でき、
  約 95%($0.1514 / 0.1587 \approx 0.954$)が周波数の違いから来ている。高周波の数個の部分空間の分解能を保つことが大きく効くことを
  示唆する。ただし、この分解は標準偏差を伴わない診断量であり、判定はしていない。また、2 つの寄与の和で書けるのは差の定義による
  恒等式であり、2 つの要因の相互作用がないことを示すものではない。

### 7.4 実験 B(短い微調整の後の比較)

**判定(事前宣言した基準による)**: **支持。** 長さ $4L$ で 400 ステップ微調整した後、シードごとの差 $d_k$ は
$[0.0071, 0.0071, 0.0072, 0.0075, 0.0071]$、$\Delta_B = +0.0072$、$\sigma_B = 0.0012$ で、$\Delta_B - 2\sigma_B \approx +0.0048 > 0$ である。
$\sigma_B$ は $\sigma_{\mathrm{seed}} = 0.0001$ と $\sigma_{\mathrm{window}} = 0.0012$ から求めた値で、**ほぼ記事間のばらつきで決まっている**
(シード間のばらつきは小さく、ノイズ床の YaRN + 微調整のシード間の標本標準偏差も 0.0003 である)。旧基準の $\sigma_B$ は 0.0007 だった。

**診断量**:

- 微調整の前後($[L, 4L)$、シード平均): 位置補間は 1.8570 → 1.6737、YaRN は 1.6983 → 1.6665 だった。手法間の差は微調整前の
  0.1587 から 0.0072 に縮んだ。
- $[0, L)$ は、微調整後に位置補間 1.6758、YaRN 1.6654、底の調整 1.6592 で、スケーリングなし・微調整なしの 1.6552 より
  それぞれ 0.0206、0.0102、0.0040 高い。
- 底の調整 + 微調整(診断用、シード 2 個): $[L, 4L)$ は 1.6708 で、YaRN(1.6665)と位置補間(1.6737)の間だった。
- 記事ごとのシード平均の差は 12 本中 11 本で正で、記事 346(評価窓 2 個)のみ $-0.0211$ だった。
- gradient clipping の発動率は 0.09〜0.18 だった。

**事後的な解釈(検証していない)**:

- 微調整によって位置補間の欠点の大部分が埋まり、手法間の差は実験 A の約 1/22($0.0072 / 0.1587 \approx 0.045$)に縮んだ。
  位置補間の原論文 [2] の、補間したモデルは短い微調整で長い文脈に適応するという主張と整合する。それでも差は消えず、同じ
  微調整の予算では YaRN が有利なまま残った。
- YaRN で採用された学習率($10^{-4.5}$)は位置補間($10^{-4}$)より小さかった。YaRN は微調整前から学習長を超える位置で
  崩れていない(1.6983)ので、大きく重みを動かす必要がなかった、と解釈できるが、学習率の違いが対比量に与えた影響は分けて
  測っていない。
- 微調整による $[0, L)$ の悪化は、底の調整が最も小さかった。学習時に底を変える方式が短い文脈の性能を保ちやすいことを示唆するが、
  診断用の条件(シード 2 個、較正せず YaRN の学習率を使用)であり、判定はしていない。

### 7.5 実験 C(伸ばした文脈を実際に使っているか)

**判定(事前宣言した基準による)**: **支持。** YaRN + 微調整のモデルで、位置 $[3L, 4L)$ のトークンを直前の $L$ トークンだけから
予測したときと全文脈で予測したときの差は、シードごとに $c_k = [0.0024, 0.0025, 0.0024, 0.0023, 0.0024]$、$\Delta_C = +0.0024$、
$\sigma_C = 0.0007$($\sigma_{\mathrm{seed}} = 0.0000$、$\sigma_{\mathrm{window}} = 0.0007$)で、$\Delta_C - 2\sigma_C \approx +0.0010 > 0$ である。
$L$ より遠い文脈は予測をわずかに改善しており、伸ばした文脈は使われている。ただし、**記事ごとのシード平均の差は 12 本中 4 本が
0 以下** だった(記事 339: $-0.0018$、341: $-0.0014$、349: $+0.0000$、353: $-0.0030$)。旧基準の $\sigma_C$ は 0.0006 だった。

**診断量**(同じ位置 $[3L, 4L)$ の $b^{\mathrm{truncated}} - b^{\mathrm{full}}$、微調整なしは $s = 4$): スケーリングなし $-0.4491$、
NTK-aware $-0.1950$、位置補間 $-0.0109$、YaRN $+0.0037$、位置補間 + 微調整(シード 2 個の平均)$+0.0014$。

**事後的な解釈(検証していない)**:

- 微調整なしのスケーリングなし・NTK-aware・位置補間は、全文脈で予測すると直前の $L$ トークンだけのときより悪く、長い系列を入力
  すること自体が予測を損ねている。YaRN は微調整なしでも差が正で、崩れずに遠い文脈を使えている。**「長い系列で崩れないこと」と
  「長い文脈を使うこと」は別の性質** であり、前者は手法間で大きく異なるが、後者の利得はこの規模では 0.0024 bits-per-byte 程度と
  小さい。
- 利得が小さいことは、長距離の依存が弱いと見込んだ 6.1 節の宣言と整合する。しかし、その原因がモデルの規模(4 層・$d_{\mathrm{model}} = 256$)
  にあるのか、コーパス(Wikipedia の記事)の性質にあるのかは特定していない。

### 7.6 実験 D(静的なスケーリングの短い系列でのコスト)

**判定(事前宣言した基準による)**: **支持。** 長さ $L$ の区間で、$\Delta_D = b_{\mathrm{yarn}, s=4} - b_{\mathrm{none}} = +0.0407$、
$\sigma_D = 0.0018$ で、$\Delta_D - 2\sigma_D \approx +0.0371 > 0$ である。静的な YaRN を常に適用すると、学習長以内の系列の bits-per-byte が
スケーリングなし(1.6752)より高くなる(1.7160)。記事ごとの差は記事 346(評価窓 2 個、$-0.0058$)を除く 11 本で正だった。
旧基準の $\sigma_D$ は 0.0008 だった。

**診断量**:

- 位置補間($s = 4$)での同じ量は $+0.1867$(1.8619 対 1.6752)で、YaRN の約 4.6 倍だった。
- dynamic YaRN は、長さ $L$ の全区間で損失と logits がスケーリングなしと完全に一致した(アサーション)。
- 位置 $[L, 4L)$ で、dynamic YaRN(区間ごとの前方からの評価による近似)は 1.6854、静的な YaRN($s = 4$)は 1.6983 で、差は $-0.0129$
  ($\sigma = 0.0006$)だった。
- 記事の中の長さ $L$ の区間でのスケーリングなしの bits-per-byte は 1.6752 で、P0 の評価集合(記事の境界をまたぐ窓を含む)の
  1.6681 よりやや高い。

**事後的な解釈(検証していない)**:

- 静的なスケーリングのコスト($+0.0407$)は、実験 B の微調整後の手法間の差($+0.0072$)の約 5.7 倍である。短い入力が多い用途では、
  YaRN を常に有効にするコストが、手法の選択による差より大きくなりうる。3.8 節の Qwen3 のモデルカードの注意(静的な YaRN は短い
  テキストの性能に影響しうる)と、dynamic scaling の動機を、この小型モデルでも定量的に示している。
- dynamic YaRN は学習長以内のコストをなくしたうえで、$[L, 4L)$ でも静的な YaRN より低かった。短い接頭辞を小さい倍率で処理する
  ことが効いていると考えられるが、区間ごとの近似による評価であり、トークンごとに倍率を変える厳密な評価や、KV キャッシュを
  使う生成での振る舞いは確かめていない。

### 7.7 まとめ

**判定の一覧**(再実行、最終判定):

| 実験 | 検証すること | 対比量・標準偏差 | 判定 |
|---|---|---|---|
| A | 微調整なしで、YaRN は位置補間より学習長を超える位置の bits-per-byte が低い | $\Delta_A = +0.1587$、$\sigma_A = 0.0049$ | 支持 |
| B | 同じ短い微調整の後も、YaRN は位置補間より学習長を超える位置の bits-per-byte が低い | $\Delta_B = +0.0072$、$\sigma_B = 0.0012$ | 支持 |
| C | YaRN + 微調整のモデルで、全文脈は直前の $L$ トークンだけの文脈より bits-per-byte が低い | $\Delta_C = +0.0024$、$\sigma_C = 0.0007$ | 支持 |
| D | 静的な YaRN は学習長以内の系列の bits-per-byte をスケーリングなしより高くする | $\Delta_D = +0.0407$、$\sigma_D = 0.0018$ | 支持 |

**事前宣言した基準から言えること**(3 節の本筋への対応):

- **何が壊れるか**: 学習長を超える位置で、スケーリングなしのモデルの予測は評価長とともに悪化する(実験 A の診断量)。
- **各手法はそれをどう直すか**: 微調整なしでは、YaRN が位置補間より大きく良い(実験 A)。その差の大部分が
  周波数の違いによることは、診断量からの事後的な解釈である(7.3 節)。
  同じ短い微調整の後も YaRN の優位は残るが、差は小さい(実験 B)。
- **伸ばした文脈は使われるか**: YaRN + 微調整のモデルは $L$ より遠い文脈を使っており、その利得は小さい(実験 C)。
- **静的なスケーリングのコスト**: 静的な YaRN は学習長以内の性能を下げる(実験 D)。

**言えないこと**:

- 大規模なモデル(Llama 系など)での効果量。本トピックのモデルは 4 層・$d_{\mathrm{model}} = 256$ で、効果量はそのまま外挿できない。
- LongRoPE など、実装していない手法との比較。
- passkey retrieval のような、長い文脈の中から特定の情報を取り出す能力。本トピックは bits-per-byte のみで評価した。
- 一般化の限界: $L = 256$・$d = 32$ の構成では、YaRN と位置補間の周波数の違いは部分空間 0〜6 からしか生じない(3.5 節、5.5 節)。
  $L$ や $d$ が大きいモデルでは外挿される部分空間の数が変わり、同じ $\alpha, \beta$ でも手法間の差の大きさは変わりうる。
- 実験 B の結論は、$T = 400$ ステップという固定の微調整の予算のもとでの比較であり、各手法が収束した状態での比較ではない。

**事後的な解釈の一覧(検証していない)**:

- 温度の補正は、倍率が大きいほど学習長を超える位置で効き、学習長以内ではわずかに不利に働く(7.3 節)。
